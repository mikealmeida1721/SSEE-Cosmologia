Este es, de los papers SSEE revisados hasta ahora con este mismo protocolo, el
**mejor sustentado en trazabilidad numérica**: prácticamente cada valor cuantitativo
tiene un JSON fuente con bloque `_procedencia` (commit + script + sha256 de
